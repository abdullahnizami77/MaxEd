### One note on certifi

`certifi` is MPL-2.0, which is a weak copyleft licence rather than a pure permissive one. It is a transitive dependency of `httpx` and it ships a bundle of root certificates. MPL-2.0 applies its share-alike obligation at the level of the MPL-licensed files themselves. Those files are used unmodified and are not redistributed as part of this repository, so no source-disclosure obligation reaches any code here. It is called out rather than glossed over because the licence class genuinely differs from the others in this list.

## Reproducing this list

```bash
./.venv/bin/python -c "
from importlib.metadata import distributions
for d in sorted(distributions(), key=lambda d: d.metadata['Name'].lower()):
    m = d.metadata
    lic = m.get('License-Expression') or m.get('License') or 'see classifiers'
    print(f\"{m['Name']:28} {d.version:12} {lic}\")"
```
